# NASA Cadet Space Academy

This is a p5.js game project prepared for GitHub Pages.

## Files
- `index.html` loads the p5.js library and the game sketch.
- `sketch.js` contains the game code.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html` and `sketch.js` to the repository's root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish. Your game URL will look like:
   `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`

The game uses the p5.js 1.9.0 library from cdnjs, so an internet connection is needed when it loads.
